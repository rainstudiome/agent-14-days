# 常见问题

## 为什么不用 ORM？

只有一张表、五条 SQL，ORM 带来的依赖比它省下的代码多。

## 为什么用 SQLite？

不用单独部署数据库，备份就是复制一个文件。个人笔记的数据量，SQLite 绰绰有余。

## 能换成 PostgreSQL 或 MySQL 吗？

目前不支持，存储层只写了 SQLite。要支持的话，需要给 `storage.py` 换一套实现。

## 支持多用户吗？

不支持。没有登录，也没有权限控制，所有人看到的是同一批笔记。不要把它直接暴露在公网上。

## 搜索支持中文吗？

支持。搜索是在标题和正文里做子串匹配（SQL 的 `LIKE`），不分词，所以搜"鸡蛋"能找到"西红柿炒鸡蛋"，但搜"番茄"找不到"西红柿"。

## 标题能自己指定吗？

不能。标题总是用正文第一行生成，最多 30 个字符，超出部分截断。
